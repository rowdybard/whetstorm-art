# Starter arena concept set

These six original 2D concepts explore the future starter arena described in
`OWNER_ART_BRIEF.txt`, using `public/website-hero-arena.png` as a style
reference. The proposed starter arena is not the existing PvP Coliseum. These
pictures are not 3D models, runtime assets, final dimensions, or an implemented
layout. Individual prompt, reference and hash records are listed below.

| Piece | Concept | Provenance |
| --- | --- | --- |
| Wall | `docs/design/whetstorm-concepts/arena-wall.png` | `docs/design/whetstorm-concepts/arena-wall-provenance.json` |
| Gate | `docs/design/whetstorm-concepts/arena-gate.png` | `docs/design/whetstorm-concepts/arena-gate-provenance.json` |
| Stands | `docs/design/whetstorm-concepts/arena-stands-bay.png` | `docs/design/whetstorm-concepts/arena-stands-bay-provenance.json` |
| Banner | `docs/design/whetstorm-art/arena-banner-concept.png` | `docs/whetstorm/arena-banner-concept-generation.json` |
| Floor | `docs/design/whetstorm-concepts/starter-arena-floor-module.png` | `docs/whetstorm/starter-arena-floor-module-generation.json` |
| Tower transition | `docs/design/whetstorm-concepts/starter-arena-tower-transition.png` | `docs/design/whetstorm-concepts/starter-arena-tower-transition.json` |

The tower is an optional transition study and overlaps the gate's towers. The
standalone banner and decorative banners in the other images are explorations,
not an approved emblem or final cloth design. The gate finial and floor edges
are close to their image boundaries.

Before modeling, establish the starter-area layout and player scale, then
reconcile the wall, gate and tower heights, arena radius, openings, collision
and sight lines. The single views do not define backs, undersides or attachment
points. Wall end piers, stand end piers and gate buttresses need compatible
seams; the tower's side rings do not prove a working connection. The floor
perimeter blocks and sand marks are not a proven seamless tile. The gate needs
separate open/closed behavior if gameplay requires it. Verify camera,
accessibility and encounter readability in the full candidate; do not reuse
the existing PvP layout's dimensions as a starter-arena specification.
