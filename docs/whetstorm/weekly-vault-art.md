# Weekly vault door art

The three SVG doors in `public/ui/weekly-vault/` were drawn specifically for
Whetstorm in this task using original vector shapes and gradients. No reference
image or upstream media was used. The locked door uses a keyhole, the normal door a cool diamond,
and the heroic door a warm star. The adjacent UI text remains the accessible
source of state and difficulty.

`weekly-vault-size-review.png` shows the shipped SVGs at 128px and 64px on a
dark background. The three states remain distinguishable at both sizes.
